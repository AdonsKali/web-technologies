# Лабораторная работа №1: Основы HTML и структура веб-страницы
#### 📋 Описание проекта

Данная работа представляет собой создание HTML-страницы «О себе» в рамках изучения основ веб-разработки. Страница разработана в соответствии с заданием и тематикой «Путешественник», с применением семантических тегов HTML5 и базовых стилей.
#### 🎯 Цель работы

Освоить базовую структуру HTML-документа, научиться использовать семантические теги, работать с текстом, списками, ссылками, изображениями и формами обратной связи.

#### 🛠️ Используемые технологии

    HTML5 — семантическая разметка страницы

    CSS — базовое оформление (inline-стили)
