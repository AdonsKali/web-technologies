# Лабораторная работа №2: Базовые и продвинутые возможности CSS
#### 📋 Описание проекта

Данная работа представляет собой модернизацию прошлой лабораторной работы.. Страница разработана в соответствии с заданием и тематикой «Путешественник», с применением семантических тегов HTML5 и продвинутых более сложных CSS стилей.
#### 🎯 Цель работы

Научиться подключать стили, работать с селекторами, типографикой, цветами,
отступами, позиционированием и псевдоклассами

#### 🛠️ Используемые технологии

    HTML5 — семантическая разметка страницы

    CSS — продвинутое оформление
