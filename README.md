## Лабораторная работа №5: DOM и взаимодействие с элементами страницы

#### Описание проекта
Добавлена работа с DOM деревом непосредственно через `script.js`. Переделана секция со списком навыков.

#### Цель работы
Научиться манипулировать DOM деревом, находить элементы, изменять
содержимое и стили, а также сохранять состояние страницы между перезагрузками через
localStorage. 


#### Что реализовано
- Поиск элементов (`getElementById`, `querySelector`).
- Добавление навыка через `prompt`, создание `<li>` и кнопки «Удалить».
- Очистка списка (через `querySelectorAll` и `remove()`).
- Переключение светлой/тёмной темы (добавление класса `dark-theme` к `<body>`).
- Скрытие/показ списка навыков (класс `invisible`).
- Сохранение состояния (навыки, тема, видимость) в `localStorage` и восстановление при перезагрузке.
- Обработка ошибок: проверка наличия элементов в DOM.
