## Лабораторная работа №4: Основы JavaScript

#### Описание проекта
Добавлен скрипт `script.js`, который рассчитывает параметры маршрута
путешественника: общую длину, длинные и короткие перегоны, самый длинный участок.

#### Цель работы
Познакомиться с синтаксисом JS, базовыми конструкциями и логикой.


#### Что реализовано
- `prompt` — ввод имени пользователя
- `alert` — приветствие и итоговая фраза
- `console.log` — детальная статистика маршрута
- `findMaxDistance(arr)` — самый длинный перегон
- `filterLongRoutes(arr)` — перегоны > 100 км
- `calculateTotalDistance(arr)` — общая длина маршрута
- Цикл с условием — подсчёт коротких перегонов (≤ 30 км) и их суммы
- Условие — рекомендация разбить маршрут, если длина > 500 км
