# Лабораторная работа №3: Вёрстка макета с помощью Flexbox и Grid

#### Описание проекта

Данная работа представляет собой развитие предыдущей лабораторной работы: страница «Путешественник» дополнена адаптивной вёрсткой на Flexbox и CSS Grid. Реализованы карточки навыков с прогресс-барами, дашборд статистики и горизонтальное меню, которое корректно перестраивается на планшетах и мобильных устройствах. Страница свёрстана с применением семантических тегов HTML5 и медиа-запросов.

#### Цель работы

Освоить Flexbox для одномерных макетов и CSS Grid для двумерных, а также принципы адаптивной вёрстки.

#### Используемые технологии

- **HTML5** — семантическая разметка страницы (`<article>`, `<section>`, `<dl>`, `<dt>`, `<dd>`, `<nav>`, `<aside>`)
- **CSS** — горизонтальное адаптивное меню и ряд карточек навыков
